## 5. 保存失败与通知（A06～A08）

建议用独占文件锁稳定制造错误，避免只改“只读”属性但未实际阻止保存：先打开并修改一个测试文件，再在单独的 PowerShell 中执行下列命令，将路径改为该文件绝对路径。保持该 PowerShell 窗口打开。

```powershell
$acceptanceLock011 = [System.IO.File]::Open('D:\你的测试目录\lock-a.txt', 'Open', 'ReadWrite', 'None')
```

释放锁时在同一 PowerShell 执行：

```powershell
$acceptanceLock011.Dispose()
```

- [x] 文件被锁时 `Ctrl+S`：右下角显示保存失败；等待十余秒仍保留。正文和脏标记保留，不因提示出现而关闭文档。
- [x] 连续重复保存：同类失败更新次数，通知不无限堆叠；每次操作仍尝试保存。关闭通知后短时重复保存不持续刷屏，脏标记仍在。
- [x] 展开详情、滚动并复制，粘贴到记事本：能看到保留的路径、错误码和诊断；若截断或省略，则展示及复制均明确标记。
- [x] Toast 出现时编辑器不自动失焦；通知处于窗口右下角、状态栏上方，不挤占编辑区；缩窄窗口后详情不溢出。
- [x] 文件锁定时尝试关闭文档或退出，并在确认中选保存：失败后文档/窗口仍保留，不能因 Toast 登记完成而关闭。
- [x] 释放锁，再保存：对应失败提示解除，磁盘正文正确、脏标记消失；普通保存成功不额外弹出成功提示。
- [x] 对第二个测试文件制造失败，分别重试：一个文件成功不能清掉另一个文件尚未解决的错误。
- [x] 对至少四个测试文件制造失败：最多三条 Toast 可见，多文件可以汇总，文件数与重复次数有区分，新的关键失败不会一直不可见。
- [x] 若测试大量不同失败触发容量裁剪，检查省略/截断标记；未触发容量阈值就记为“未人工覆盖”，容量边界已有自动单测，不把未观察到写成通过。
