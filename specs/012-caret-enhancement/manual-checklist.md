## 1. 多光标与同步编辑（A01—A03）

- [x] **M01 创建／移除**：用 `Alt+Shift+Click` 在同行不同列和不同行添加三个光标；再次点已有光标可移除，最后一个保留；相同位置没有重复光标。普通点击恢复单选区。
- [x] **M02 上下增加**：用 `Ctrl+Alt+↑/↓` 增加光标，原有光标保留。覆盖长行 → 短行 → 长行：短行落在行尾，再到长行尽量恢复目标列；首尾不越界、不插入空格。若按键被系统截获，记录现象。
- [x] **M03 普通移动合并**：在 `ABCDE` 的第 0、1、3 个字符边界放三个光标，按一次左方向键，应变成第 0、2 个边界的两个光标。再检查上下移动遇到文档边界／短行时的位置重合也会合并，同一行不同列不会误合并。
- [x] **M04 独立选区**：`Alt+Shift+Drag` 添加不同长度的独立选区；`Shift+方向键` 同时扩展各选区。重叠后正常合并，不变成矩形选区，不出现重复编辑。
- [x] **M05 同步编辑**：在三个光标处分别试输入、Backspace、Delete、Enter 和既有缩进操作；用输入替换多个选区。所有目标同时处理，文本无遗漏或重复。
- [x] **M06 撤销／重做**：同步编辑或删除换行导致光标合并后，用 `Ctrl+Z` 和 `Ctrl+Shift+Z` 检查完整文本及对应选区恢复。一次同步操作不需要按光标数量逐个撤销；连续普通输入允许沿用原有历史分组。

## 2. 分段剪贴板（A04—A06）

在第一个临时标签页放入：

```text
aaAAaa
bbBB
CCcc
ddDDdd
```

用普通拖选和 `Alt+Shift+Drag` 建立三个非空选区，按文档顺序分别为：`AA`、实际跨行的 `BB` 加换行加 `CC`、`DD`。中间一段包含真实换行，不能当成两个源选区。

在第二个标签页放入下列文本，并在三个冒号后分别放光标：

```text
1:
2:
3:
```

- [x] **C01 三段到三目标**：在第一个标签页 `Ctrl+C`，跨标签页粘到三个光标。结果必须如下，证明跨行片段没有被错误拆分：

  ```text
  1:AA
  2:BB
  CC
  3:DD
  ```

- [x] **C02 添加顺序**：故意倒序建立源选区或目标光标，重复 C01。仍按文档位置一一对应，不按点击顺序分配。
- [x] **C03 多段回退**：将上述三段分别粘到一个目标、两个目标。一个目标收到完整 `AA`、`BB`、`CC`、`DD` 四行文本；两个目标各收到这份完整文本，不截断、不循环分配。
- [x] **C04 单段跨行**：只复制一个跨行选区 `BB` 加换行加 `CC`，粘到两个光标。每个光标都插入完整两行内容，不将 `BB` 和 `CC` 分给两个目标。
- [x] **C05 外部文本与过期信息**：在其他应用复制 `X` 和 `Y` 两行，粘到两个光标应逐行分配；粘到三个光标则各插入完整两行。Sorakada 复制后，再在外部复制相同纯文本，不能误用 Sorakada 旧分段。剪贴板历史若丢失私有分段，允许按外部纯文本规则处理。
- [x] **C06 空光标／空行**：非空选区与空光标混合时只复制选中文本；全为空光标时复制／剪切整行，同一行多个光标只处理该行一次。单独复制一个空行，再粘到空光标，应新增一个空行。
- [x] **C07 文本完整性**：覆盖目标本身带选区、片段含空行／尾部换行、LF／CRLF 文档；复制字面 `\n`、`\t` 后粘贴，反斜杠及字母原样保留，不变成换行或 Tab。
- [x] **C08 剪切与历史**：对上述分段做 `Ctrl+X`、粘贴、撤销、重做。只删除源选区内容，目标按规则替换；一次剪切或粘贴能整体撤销，文本和选区正常恢复。

## 3. Esc、中文输入法与搜索（A07—A08）

- [x] **E01 层级退出**：先打开空查询的搜索栏，再回编辑区创建多选区，最后打开视图菜单及其子菜单。连续按 Esc：子菜单 → 主菜单 → 搜索栏 → 多选区收敛为主选区；每次只处理一层。若保留的主选区有文本，再按一次 Esc 才折叠为光标。
- [x] **E02 局部焦点**：分别在编辑区、搜索输入框、Explorer 搜索／重命名中按 Esc；最高层弹窗／菜单优先，其余操作遵守原有局部退出行为，不顺带清掉编辑器选区。关闭确认对话框时，Esc 只取消对话框。
- [x] **E03 中文 IME**：在三个光标下输入中文，分别试拼音组合、候选切换、空格／数字选词、提交、Esc 取消候选。各光标文本一致，不漏字、不重复提交；候选期间 Esc 不关闭搜索或收拢多光标，动画不干扰候选位置。
- [x] **E04 搜索与替换**：有多个选区时打开查找，预填取自主选区；搜索上／下一个和单次替换正常，允许收敛为单个匹配；全部替换沿用原范围，不因光标数量重复替换。当前匹配高亮保持正确。
- [x] **E05 标签页**：两个标签分别建立不同多选区，来回切换后各自保留；旧页动画不影响新页，未保存状态保持正常。

## 4. 键盘与鼠标光标动画（A09、A13）

- [x] **V01 键盘短导航**：左右、上下移动及少量可见多光标移动有自然过渡；长按、快速反向时跟随最新目标，没有排队、长拖尾或跨屏飞行。
- [x] **V02 普通单击**：从一个空光标开始，在正文内五行以内短距离普通左键单击，能看到轻量过渡；连续点不同位置能及时中断。同位置点击没有多余跳动。
- [x] **V03 立即编辑**：方向键移动或单击后，立刻输入、删除、粘贴。内容作用于真实新位置，不等待动画完成；短距离视觉过渡可接续最新目标。
- [x] **V04 手势排除**：拖选立即显示真实选区；双／三击、Shift 扩选、Alt+Shift 多光标手势、多光标收敛或非空选区折叠没有额外光标过渡。拖选后键盘移动仍正常。
- [x] **V05 可见性与距离**：远距离点击、超过短距离阈值或长行旧光标横向不可见时直接落位；行号／滚动条点击、右键和 IME 期间不误触发单击动画。普通鼠标点击不额外启动平滑视口滚动。

## 5. 视口跟随及动画中断（A10—A11）

- [x] **S01 常规跟随**：在可翻页文本中试 PageUp／PageDown，以及方向键移出可见区域；适中距离有轻量滚动，主光标和最终位置正确。窄窗口及正常滚动条存在时也检查一次。
- [x] **S02 大跨度跳转**：在约十万行文档中反复 `Ctrl+Home/End`。允许直接跳转；不能依次滚过中间所有行或明显卡住，End 最终正常显示文档末尾及底部对齐。
- [x] **S03 新导航打断**：滚动跟随尚未结束时，立刻反向导航、点击当前可见位置或按 `Ctrl+Home/End`。旧动画不继续执行、不把视口拉回原目标。
- [x] **S04 手动滚动打断**：动画期间使用滚轮、触控板或拖动滚动条，视口立即交给手动操作，停止后不回拉。无触控板时记录该子项未执行。
- [x] **S05 生命周期打断**：动画中立即输入、开始中文组合、切换标签、切换到其他应用、调整窗口尺寸；应用支持的字号／布局变化也检查一次。没有残留动画、错位或视口回拉，恢复操作正常。

## 6. 开关与减少动画（A12）

- [x] **P01 应用开关**：在“视图 → 平滑光标与滚动”关闭后，键盘光标、普通单击及视口跟随都直接落位；重新开启恢复。勾选状态正确，切换旧标签页同样生效。
- [x] **P02 偏好保存**：关闭动画后正常退出并重启，开关仍关闭；再开启并重启，状态仍保留。
- [x] **P03 系统偏好**：应用开关开启时，在 Windows 系统设置中关闭动画效果，本期动画应停用；运行中切换也能及时生效。恢复系统动画后，仍由应用开关决定是否启用。

## 7. 补充回归与性能降级

- [x] **R01 大量光标**：建立超过十个光标，同步输入、删除、撤销仍响应正常；允许光标动画关闭。较多光标或大文件的视觉降级不能改变实际编辑结果。
- [x] **R02 长行与复杂字符**：在含中文、Tab、emoji 及超长行的文本中移动和上下增加光标；目标位置合理，没有拆坏字符。水平滚动可保留原生，光标不穿过不可见区域飞行。
- [x] **R03 保存与恢复**：临时文件多光标编辑后保存、关闭并重新打开，内容正确；取消未保存关闭后文本仍在。若测试外部重载，接受重载后不残留旧动画，选择位置按既有规则保留／夹取。
- [x] **R04 文件硬上限**：十万行文档中，不滚动的位置输入、短距离删除／粘贴仍有光标过渡；超过 20 万行或 1000 万个 UTF-16 单元的文档全部直接定位。单次插入／删除超过 500 个 UTF-16 单元或 5 个换行时降级，等长大段替换也不强行动画。无需为本轮重新制作大量规模组合，重点复查原十万行文件和一项超限样例。

## 8. 验收后新增优化（A14—A15，已通过）

- [x] **N01 普通键入**：单光标及少量多光标下输入、连续快速键入、替换选中文本、普通换行；视觉光标过渡，实际内容与选区即时正确，连续输入没有排队。编辑为 120ms、左右导航保留 150ms，曲线相同，交替操作不残留上一类操作的时长。
- [x] **N07 键入动画对比**：在同一行先关闭、再开启动画，慢速单字输入及快速连续输入分别对比；开启后应有可感知的自然过渡，连续输入不在每字前先跳到上一终点。与左右导航的曲线一致；首字响应不应因固定等待而变慢。重点验证本轮较柔和曲线及输入衔接，不能仅凭自动化 class 断言判通过。
- [x] **N02 拼音组合与中文提交**：逐字拼音键入、候选切换（含屏幕位置改变与不变场景）及最终空格／数字／回车上屏均呈现平滑光标过渡；连续快速输入自然接续，不先回跳上一终点或产生排队延迟。特别检查等长的拼音／汉字替换：字符索引相同但字形宽度改变时仍应平滑，屏幕位置不变时不制造动画。Esc 取消组合立即对齐；输入法候选框定位准确不被拖慢；覆盖多光标输入，不漏输、不重复提交、不额外增加文本或撤销步骤。
- [x] **N03 删除、粘贴与中断**：短距离 Backspace、Delete、删除选区及粘贴复用光标过渡，正文与选区立即生效；Delete 未改变屏幕位置时不制造动画。连续键入／删除／粘贴顺畅接续；剪切、撤销／重做及 Esc 取消组合立即对齐。开始拼音组合本身不强行掐断接续，原生滚动不回拉；关闭开关或系统减少动画时均不播放。
- [x] **N04 搜索近距离定位**：搜索框保持焦点，切换相邻匹配、直接搜索定位、单次替换后定位下一匹配；视口短距离平滑到达，匹配高亮、选区和最终居中习惯不变，已对齐时不多余晃动。
- [x] **N05 搜索大跨度定位**：长文档中跳到远处匹配或首尾循环，先定位到目标附近再短距离收尾，不滚过所有中间行；耗时不随距离增长，目标位置与最终对齐正确。
- [x] **N06 自动定位中断与生命周期**：定位动画中连续跳转、输入、滚轮／触控板／拖动滚动条，旧目标不会拉回视口；切换标签页或接受外部重载仍直接恢复，不播放搜索定位过渡。
