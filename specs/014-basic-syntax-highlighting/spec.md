# Sorakada 014 — 基础语法高亮与 Tab 缩进

**日期**：2026-10-17

**状态**：已实现，人工验收通过（2026-10-18 用户确认）；Tab 光标处插入修正及最终四项门禁均已通过。

## 目标

复用现有 CodeMirror 6，为常见代码及文本格式提供基础语法高亮，修复编辑区域按 Tab 跳到其他按钮的问题。本版以原生能力和最小侵入实现为主，后续版本再优化语言体验。

## 决策与范围

1. 使用官方 `@codemirror/language-data` 语言目录及 `LanguageDescription.matchFilename`，按当前文档的真实文件名／扩展名识别语言。识别规则、支持的格式及混合语言行为沿用官方目录和语言包，不维护第二套映射或专属解析逻辑。
2. 覆盖官方目录现成支持的常见格式，包括 JavaScript／TypeScript／JSX／TSX、HTML／CSS、JSON、Markdown、Python、Rust、C／C++、Java、Go、SQL、XML、YAML，以及目录已支持的 Shell、配置等文本格式。无扩展名的特殊文件只采用目录已有规则。未命名、纯文本及无法识别的文件保持普通文本；本版不做内容猜测或手动语言切换。
3. 调用匹配描述的原生 `load()`，按需加载语言支持；不静态导入所有解析器。使用原生缓存与解析调度，不自行实现解析线程、缓存层、节流或大文件模式。构建产物必须保留语言模块的动态分包，不能被现有统一 CodeMirror chunk 配置吞并。所有模块随应用打包，运行时不从网络下载。
4. 保持现有深色编辑器外观，仅使用官方 One Dark 的 `oneDarkHighlightStyle` 与原生 `syntaxHighlighting` 提供可读的语法配色，不覆盖整个应用／编辑器主题，也不建立自定义 token、语言配色或语义高亮系统。保留语言支持和 `basicSetup` 的原生解析、括号及编辑能力，不逐语言调整其行为。
5. 打开文件、切换文档、成功另存为或内部重命名／移动更改文件名后，语言应与当前绑定一致；外部重载保留正确语言。异步加载不得阻塞编辑，也不得将旧文件／旧视图的结果应用到另一文档。未知格式或加载失败安全退回普通文本，避免未处理的 Promise 异常；本版不新增提示或自动重试机制。
6. 语言配置使用 CodeMirror 的扩展与 `Compartment` 重配置，沿用现有单视图、多 `EditorState` 的文档架构。高亮加载／重配置不改变文本、脏状态、保存基线、撤销栈、选区、主光标或滚动位置。外部重载仍遵循原有重载语义。
7. **2026-10-18 用户实机反馈修订，取代首轮 `indentWithTab` 的无选区整行缩进行为**：无非空选区时，Tab 在每个光标处插入一个缩进单位的空白（当前沿用框架默认两空格），不在行首整体后移；存在非空选区时继续使用原生 `indentMore` 缩进选中行，Shift+Tab 继续使用原生 `indentLess` 反缩进。插入使用 CodeMirror 原生选区替换事务和选区映射，支持多光标及撤销／重做，遵守只读状态。不新增缩进配置、自动探测或逐语言规则。
8. Tab 绑定仅作用于编辑器，不截获搜索框、弹窗和其他按钮的正常焦点导航；保留框架 Tab 焦点退出能力（如 Ctrl+M 切换 Tab 焦点模式）。不得增加全局 Tab 拦截，也不得破坏已有 IDEA 快捷键、撤销／重做、IME、多光标、列选择、智能选区、选区背景或光标动画。

## 架构基线与约束

- [仓库规则](../../AGENTS.md) 与 [013 规格](../013-smart-selection-column-editing/spec.md) 继续适用；本规格只取代之前版本“暂不提供语法高亮”的范围限制。
- `src/editor/editorConfig.ts` 是统一状态工厂，已安装 `basicSetup` 和应用扩展；`Editor.tsx` 只管理视图生命周期；`editorHandle.ts` 是应用到视图的桥。
- `DocumentManager` 持有文件路径和每文档状态；文件打开、外部重载及统一路径更新处是语言元数据的接入点。CodeMirror 继续独占实时文本，Rust 的字节／BOM／EOL 与保存语义不变。
- 不引入 LSP、诊断、格式化、运行代码、额外补全系统、语言状态栏、主题切换、手工 token 装饰或新框架；不重构已有选区和快捷键机制。
- 只建立必要的小型语言接入模块和薄绑定。Leader 负责规格、接口决策、审查与集成；Worker 负责主体实现与针对性检查，不再委派下级智能体。

## 验收

- **A01**：打开 `.ts`／`.tsx`、`.json`、`.md`、`.py` 及一种配置格式的代表文件，出现对应语法高亮；未知扩展名、`.txt` 和未命名文档可正常编辑且保持普通文本。
- **A02**：快速切换不同语言文档、加载途中关闭文档，以及成功另存为／重命名为不同扩展名，不出现串语言、文本丢失或错误脏标记；重载后仍使用当前文件语言。
- **A03**：构建中语言模块保持动态分包；冷启动普通文本不要求加载所有语言解析器；语言加载失败后仍可输入、选择与保存。
- **A04**：编辑器无范围选区时，单光标或多个光标按 Tab 各自在原位置插入两空格，例如 `ab|cd` 变为 `ab  |cd`，行首不被额外修改；多行范围选区按 Tab 仍整体缩进，Shift+Tab 按原生命令反缩进。保持焦点，撤销／重做正常，只读不插入；搜索框和其他控件的 Tab 导航仍正常。
- **A05**：现有 Ctrl+W／Ctrl+Shift+W、Ctrl+F4、多光标及列选择手势、复制粘贴、选区背景和光标动画无回归；不重写其实现。
- **A06**：Worker 仅运行与变更有关的定向检查；整合后按仓库要求执行一次 `typecheck`、Vitest、前端构建、Rust 测试四项门禁。只补充保护语言识别、异步归属与缩进兼容性的必要测试，不新建实机／端到端测试体系；视觉与交互实机验收由用户完成，未执行不得标记通过。

## 实现与验证记录

- 已接入官方语言目录、按需加载与 One Dark 高亮样式，打开、切换、另存为、重命名／移动及外部重载均沿用既有文档生命周期。异步结果受当前文件与插件生命周期保护；加载失败保持普通文本，不因输入或选区更新重复重试。
- 首轮编辑器安装官方 Tab／Shift+Tab 缩进绑定，未增加全局 Tab 拦截；语言重配置采用纯 effect，相关测试验证文本、选区、撤销深度及智能选区历史保持不变。2026-10-18 的无选区 Tab 插入语义按上文第 7 条修订，首轮的整行缩进验收结论不适用于该修正。
- 首轮验证（2026-10-17）：`npm run typecheck` 通过；`npm run test -- --reporter=dot` 为 69 个文件、1606 项全部通过；`npm run build` 通过；`cargo test --quiet` 为 145 项通过。测试兼容修正后复核了类型检查与前端全量测试，未重复未受影响的 Rust 测试和构建。
- 构建产物静态导入图核对：启动仅依赖应用入口、构建运行时、vendor 和 CodeMirror 四个 JS 分包；另有 116 个延后加载分包，语言模块未被统一吞入启动包。
- 2026-10-18 用户确认人工验收通过；Tab 已修正为无非空选区时在每个光标处插入当前缩进单位，非空选区及 Shift+Tab 继续沿用原生命令。
